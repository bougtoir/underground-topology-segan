# Terminology audit (Phases 10-11)
- "Topology likelihood distance (TLD)" → renamed "topology divergence
  distance (TDD)": it is a Jaccard-type edge-set distance, not a
  likelihood.
- "Life-cycle topology profit (LTP)" → renamed "life-cycle renewal
  benefit (ΔNPC)": neutral, describes the quantity, not a normative
  'profit'.
- "Optimized" → qualified as "best-found over the generated candidate
  set"; global optimality is not certified.
- "Reconstructed network" never labelled observed utility topology.
